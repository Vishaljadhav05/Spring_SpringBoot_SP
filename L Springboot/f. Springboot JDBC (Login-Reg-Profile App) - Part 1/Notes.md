# 🛍️ Samay Collection – Frontend Project

## 📌 Project Overview
**Samay Collection** is a simple frontend website created to showcase a collection of products in a clean and user-friendly interface. 🎨

The website focuses on presenting products with:
- 🖼️ Images
- 🏷️ Names
- ℹ️ Other basic information

It is designed as a **frontend-only project** and does not currently include a backend or database. 🚫🗄️

---

## 🎯 Purpose
- Practice frontend development skills (HTML, CSS, JS, Sevlet, JSP, Controller and SpringBoot + MVC Architecture) 💻
- Build a foundation that can later be connected to a backend 🔗

---

## 🧩 Features
- ✅ Clean and responsive UI
- ✅ Simple and easy-to-navigate layout
- ⏳ No backend / database integration (yet)
